VF API

Публичный API платформы «Ваш Финдир» для бизнес-интеграций. Сейчас доступен один endpoint — приём уведомлений о лидах.

Быстрый старт

Первый успешный вызов — один запрос:

curl -X POST "{{ base_url }}/api/leads" \
  -H "x-api-token: ВАШ_ТОКЕН" \
  -H "Content-Type: application/json" \
  -d '{"text": "Новая заявка с сайта\nИмя: Иван Петров\nТелефон: +7 900 123-45-67"}'

Ответ — 200 OK с телом ok.

Аутентификация

Токен передаётся в заголовке x-api-token. Заголовок x-lead-token с токеном лида тоже принимается — старая интеграция продолжит работать без изменений.

Токен, а также логин и пароль для интерактивной документации выдаёт менеджер «Ваш Финдир».

Ошибки

КодЗначениеЧто делать
401 Невалидный или отсутствующий токен Проверить заголовок x-api-token и сам токен
502 Telegram недоступен — уведомление не доставлено Повторить запрос позже (тело запроса можно отправить заново)
503 Сервис отключён или релей лидов не настроен Сообщить менеджеру «Ваш Финдир»
